# Motivating Question

Can I imbue the persona of an influencer (publicly branded persona) into an Agent?

## Setup & Subquestions

We use Paul Saladino, a nutrition influencer, as a beginning.

First, how should we parse his knowledge?
- Podcasts
- Videos
- Online short form content

Next, how do we organize the wiki of *him*?
- Build a retrieval graph of related topics
- Nodes can be related PubMed studies

Evaluation: how do we know this is working?
- Accuracy: Perhaps we can train the agent on 80% of the knowledge corpus and see if the remaining 20% can be generated by the agent, consistent with the original.
    - Compare to baseline: use the same base model without the context, only on its pretrained knowledge of saladino
    - Another baseline: a "deep research" style agent.
    - Neutral evaluation agent whose sole goal is to determine the ACCURACY to the original source content set, not what the model is actually tuned towards (RLAIF)
    - This answers the question: why is your structure of knowledge storage any better than base chat gpt?
- For fun: Refutation
    - The important part of getting an influencer's message across is to the people on the fence / the disagreers
    - A common criticism of influencing on the whole is that messages are cherry picked.
    - For example, can our agent produce a cogent refutation against other peer-reviewed studies that seem to contradict Paul's claims? 
        - RLHF if possible with med school friends
    - This can be evaluated by another neutral agent. We can set the guidelines /  system prompt more carefully later.

Instagram Reels / TikTok / YouTube Shorts — mentioned in the README as a
possible source of Saladino's knowledge.

## Why deferred

- Scraping these platforms is ToS-risky compared to YouTube's official
  transcript surface.
- Low information density per clip relative to long-form podcasts —
  same runtime spent on [[YouTube]] long-form content yields much more
  usable corpus text.

Reconsider only if the corpus is missing topics that only show up in
short-form content.

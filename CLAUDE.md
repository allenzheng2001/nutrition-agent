# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this project is

Motivating question (full statement in `README.md`): can a public
influencer's persona — starting with nutrition influencer Paul Saladino —
be imbued into an agent, grounded in that person's own public content,
and evaluated for accuracy against a no-context baseline and a generic
research agent?

**The design wiki, not this file, is the source of truth for project
state.** Start at `docs/wiki/Home.md` and follow the `[[wikilinks]]` —
each module (sources, chunking, retrieval, agent, evaluation) is its own
node with current status, what's built vs. designed-but-not-started, and
known gaps. Check `docs/wiki/Milestones.md` before assuming anything is
done or not — it changes every session and is more current than any
summary here.

## Setup & commands

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
```

```bash
pytest tests/                                                      # all tests
pytest tests/test_chunk.py -q                                      # one file
pytest tests/test_chunk.py::test_merges_short_snippets_into_target_sized_chunks  # one test
```

Ingest the corpus (idempotent — safe to re-run; skips already-fetched IDs
unless `--force`):

```bash
python scripts/ingest_youtube.py   # data/seeds/youtube_videos.txt -> data/corpus/youtube/*.json
python scripts/ingest_pubmed.py    # data/seeds/pubmed_queries.txt -> data/corpus/pubmed/*.json
```

Ask the persona agent a question (requires `ANTHROPIC_API_KEY`):

```bash
python scripts/ask.py "What do you think about seed oils?"
```

## Architecture

A three-stage pipeline under `src/nutrition_agent/`:

1. **`ingestion/`** — one fetcher module per source (`youtube.py` wraps
   `yt-dlp` + `youtube-transcript-api`; `pubmed.py` wraps NCBI
   E-utilities), plus `chunk.py`, which merges raw text into
   retrieval-sized `Chunk`s — `chunk_snippets()` for timed YouTube
   captions, `chunk_text()` for untimed PubMed abstracts, sharing one
   `Chunk` dataclass. Each `scripts/ingest_*.py` independently drives its
   fetcher + chunker and writes JSON to `data/corpus/<source>/<id>.json`
   plus a `_manifest.json`. There's no shared `CorpusStore` abstraction
   yet — a known, deliberate gap (see `docs/wiki/Known Gaps.md`), since
   the two ingest scripts only recently converged on the same pattern.

2. **`retrieval/index.py`** — `load_corpus()` reads every
   `data/corpus/*/*.json` and flattens each document's chunks into
   `CorpusChunk` (the point where the two source-specific JSON shapes
   converge into one type); `BM25Index` does keyword search over them.
   This is an interim stand-in for the graph-structured retrieval the
   README envisions — see `docs/wiki/Knowledge Graph/`.

3. **`agent/`** — `persona.py`'s `PersonaAgent.respond()` retrieves
   context via `BM25Index`, builds a system prompt that grounds the
   model in it (cite sources, admit gaps rather than invent a position),
   and calls out through the one-method `LLMClient` protocol
   (`llm.py`'s `AnthropicClient`, default model `claude-opus-5`).
   `LLMClient` is a narrow protocol specifically so the model/provider is
   swappable and so `tests/test_persona.py` can stub it without a
   network call or API key.

**Design intent, not yet implemented:** the persona system prompt +
corpus retrieval are meant to be portable across more than one execution
engine, not just `PersonaAgent` — including a Claude Code agent session
given the same corpus and instructions, as one of the evaluation
baselines. See `docs/wiki/Agent Layer/Agent Runtimes.md`.

## Conventions worth knowing

- Corpus JSON schemas differ per source (see
  `docs/wiki/Data Contracts.md` for both) — don't assume PubMed docs have
  `video_id`/`channel`, or that YouTube chunks have `null` timestamps.
- Seed lists (`data/seeds/*.txt`) are the only place new videos/queries
  get added — `#` starts a comment, one entry per line.
- `data/corpus/` is gitignored; it's regenerated by the ingest scripts,
  never committed.
